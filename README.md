# 🖼️ 通用图片格式转换工具 (Universal Image Converter)

一个基于 Python 和 Tkinter 开发的高效、轻量、多核并发的批量图片格式转换工具。专为 Windows 用户打造，提供直观的图形界面，支持多种格式互转、转换前效果预览、多任务队列处理以及完善的错误追踪机制。

## ✨ 核心特性

### 🚀 极致的性能与稳定性
- **多核并发处理**：支持手动调节并发核心数（默认自动获取最大核心数），批量转换速度提升数倍。
- **分批处理机制**：采用 500 个文件一批的队列处理，即使面对上万张图片，也不会导致内存溢出。
- **容错与清理**：自动检测文件损坏、被占用、无权限等情况并跳过。如果转换中途出错，会自动清理残留的残缺文件。
- **智能覆盖策略**：支持“覆盖同名文件”、“跳过同名文件”、“重命名保存（如 `_1`）”三种策略，保护你的现有数据。

### 🎨 丰富的格式支持
- **输入格式**：`.webp`, `.png`, `.jpg`, `.jpeg`, `.bmp`, `.tiff`, `.gif`（支持拖拽文件夹或单文件）。
- **输出格式**：`JPG`, `PNG`, `WEBP`, `BMP`。
- **质量智能联动**：输出为 `PNG`/`BMP`（无损格式）时，质量下拉框自动禁用；输出为 `JPG`/`WEBP` 时，提供“极高画质 (原图100%质量)”到“极小体积 (原图60%质量)”的直观选项。

### 🔍 强大的预览与对比功能
- **转换前模拟预览**：在开始转换前，双击任务队列中的文件，工具会在**内存中模拟**当前质量设置下的压缩结果，左侧显示原图，右侧显示预估效果，并计算预估体积变化。
- **转换后对比**：双击左侧成功日志，可弹出实际转换后的 JPG/PNG 与原图的大小、尺寸对比，直观展示压缩率。

### 📋 贴心的任务与日志管理
- **多任务队列**：支持一次性拖拽多个文件夹或文件，队列可随时添加、移除、清空。
- **独立错误日志**：运行日志与错误日志左右分栏显示。错误日志显示**完整绝对路径**，双击可直接在资源管理器中定位该文件。
- **日志导出**：一键将运行日志和错误日志导出为 `.txt` 文件，方便反馈问题。
- **配置持久化**：自动记忆用户的输出格式、删除源文件选项、并发数、质量、覆盖策略等设置。

## 📦 如何使用

### 方式一：直接下载可执行文件 (推荐)
1. 前往本仓库的 **Actions** 页面，点击最新的构建任务。
2. 在页面底部下载 `img-converter-windows-exe` 压缩包。
3. 解压后，双击运行 `ImgConverter.exe` 即可。

### 方式二：从源码运行
如果你有 Python 环境，可以直接运行：
1. 克隆本仓库：
   ```bash
   git clone https://github.com/你的用户名/你的仓库名.git
   cd 你的仓库名
安装依赖：

bash
pip install pillow tkinterdnd2
运行程序：

bash
python webp2jpg_gui.py
📖 使用指南
添加任务：拖拽包含图片的文件夹到“任务队列”区域，或者点击“添加文件/文件夹”按钮。

预览效果：选中队列中的文件，点击“预览效果”或直接双击文件，查看压缩后的画质与预估体积。

调整设置：在“转换设置”中，选择输出格式、调整 JPG 质量、选择覆盖策略。如果不放心，可取消勾选“转换成功后删除源文件”。

开始转换：点击“开始转换”，观察进度条。随时可以点击“取消”终止任务。

检查结果：转换完成后，双击左侧日志的“成功”记录查看实际对比。如果有失败项，可在右侧错误日志中双击路径直接打开文件所在位置。

🏗️ 自行打包 (Build from source)
本程序使用 PyInstaller 进行打包。推荐使用 --onedir 模式以提升启动速度，并建议使用 UPX 压缩体积。

本地打包命令：
bash
pyinstaller --onedir --noconsole --name ImgConverter --clean --collect-all PIL --hidden-import PIL._webp --collect-all tkinterdnd2 --exclude-module PyQt5 --exclude-module PySide2 webp2jpg_gui.py
自动化打包：
本仓库已配置 GitHub Actions。每次 push 代码到 main 分支，或者手动触发 workflow_dispatch 时，会自动在 Windows 环境下打包，并生成包含所有依赖的 ZIP 压缩包（内含 UPX 压缩优化）。
